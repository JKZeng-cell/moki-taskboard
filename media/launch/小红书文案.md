# 给 Agent 一张任务卡，改稿不用翻聊天了

做一本徒步手册，路线翻译在一段对话里，装备清单散在另一段，等要改稿时，还得找上次到底交了哪一版。我给自己做了个开源插件「MOKI任务台」，把这些工作放回同一张看板。🗂️

现在我会把参考图拖进任务卡，让 Agent 按队列做。交稿后直接点开文件看，哪里不对就点「继续优化」，附上修改意见。回头还能查到每轮用了哪张图、交了哪个版本。

Windows 上有 Codex 和 DSH 两版。GitHub 搜 JKZeng-cell/moki-taskboard，DSH 用户搜 moki-taskboard-for-dsh 就能找到安装包。🌱
