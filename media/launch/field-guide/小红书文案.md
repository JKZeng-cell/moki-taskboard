# 聊完的需求，进了哪张任务卡？

在 Codex 聊完一轮改稿，最容易忘的，往往是顺口提的那句「再做一张补水卡」。我用 MOKI 任务台整理《山野手册》时，把会话归集范围设在项目目录。展开春季刊的会话，能看到它为什么被分到这里。点任务标题，卡上还留着当时说的「山口服务站和松林驿站」。🌿

手边已经有文件时更直接。在页面底部写「校对北线路线卡」，换行补要求，把路线卡拖进去，按 Ctrl+Enter。待办列马上多出一张卡，点开就能看到这次交进去的 v1。

交稿后，我在同一个任务里放大 PNG 样张，对照文字校样，再写下验收结论。排版还想改？点「继续优化」，附上改稿意见接着做。用 DSH 的话，勘察记录还能在右边打开，左手边的项目列表一直在。

🔎 GitHub 搜 JKZeng-cell，两个仓库分别叫 moki-taskboard（Codex）和 moki-taskboard-for-dsh（DSH）。配图里的春季刊是演示项目。
