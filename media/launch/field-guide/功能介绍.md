# MOKI任务台 · 功能介绍

在同一个项目里保存会话原话、任务、输入文件版本和交付记录。下面以「山野手册 · 春季刊」为例。Codex 版和 DSH 版各有一套完整面板实拍，英文首页使用英文界面，示例资料保留中文。

| 在哪里 | 如何操作 | 可以看到什么 |
| --- | --- | --- |
| 项目总览 → 看板 | 点春季刊的项目行，再切任务活动的时间维度 | 项目进度、待验收数量、选定时段内变动的任务和上线记录。 |
| 任务 | 在看板和表格间切换，点任务名称 | 同一组任务可按状态分列或逐行比较，详情里是说明、来源、输入和交付。 |
| 会话 | 开启语义归集、限定目录，展开匹配到的会话并点任务名 | 编辑的补水卡需求归入春季刊，生成待办，卡片保留归属依据所对应的来源会话和原话。 |
| 快捷输入框 | 写标题和说明、附上路线卡，选「进入待办」，按 Ctrl+Enter | 看板出现新卡，输入框给出回执。「关联输入」能找到北线路线卡.md v1。 |
| 资产 | 展开勘察记录的版本，点 v2 的预览 | 可分别打开 v1 与 v2。DSH 在右侧标签打开正文，左侧可继续浏览资产。 |
| 验收 | 点「验收本次执行」，打开排版样张，对照文字校样再确认通过 | 记录人工结论，任务从待验收转为完成。需要再改时可点「继续优化」，附加意见和文件，选择执行会话。 |

项目库和托管文件保存在本机。启动 Agent 或用模型归集会话时，所选宿主和模型会处理相关内容。
