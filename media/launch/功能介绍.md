# MOKI任务台功能导览

从聊天里的一个需求，到可以验收的具体文件。《山野手册 · 春季刊》是图集里的示例项目。两版共用任务台界面，分别接入 Codex 和 DeepSeek Harness 的执行会话。

| 页面 | 打开后可以做什么 |
| --- | --- |
| 项目总览 | 跨项目查看待验收数和整体完成率。在项目列表里点《山野手册》，进入该项目。 |
| 项目看板 | 查看任务进度、执行偏好和项目资料。选择活动日历中的日期或周期，查看期间有变化的任务。 |
| 任务 | 看板按状态分列，表格集中显示任务、状态与输入。打开任务详情可核对说明、附件、来源会话和交付，验收或继续优化。 |
| 资产 | 按类型、任务或会话找资料，展开版本记录。任务执行时固定输入版本，后来更新同名文件也能回看旧版。 |
| 会话 | 查看已关联、待归属、已忽略的会话。展开一条记录，查看归属依据、提取的任务和对应发言。 |

### 从会话自动归集到项目

在「会话 → 归集设置」启用归集并选择识别范围。本次演示使用「语义识别 · 项目及授权目录」。示例会话提出“给《山野手册》春季刊做一张北线补水卡，标出山口服务站和松林驿站的位置。”分类器自动关联春季刊，新增「制作北线补水卡并标注山口服务站和松林驿站」待办。打开卡片，在「来源会话」里能看到用户原话。项目证据不足时可在「待归属」人工确认。语义识别使用当前账号的模型额度。

### 从底部快捷提交

在快捷框首行写「校对北线路线卡」，第二行写检查要求，再添加《北线路线卡.md》。选择《山野手册》和「进入待办」，按 Ctrl+Enter 或点发送箭头。输入框显示「已加入待办」，任务详情的「关联输入」中可见《北线路线卡.md》v1。需要马上启动 Agent 时，可切换「立即执行」，再选择会话。

### 两个平台

**MOKI任务台 for Codex** 提供桌面插件入口和会话面板，可在任务台处理对应执行的审批。**MOKI任务台 for DSH** 从 DeepSeek Harness 侧栏打开，文件在右侧标签页预览，执行审批跳到对应 DSH 会话。项目库与托管文件存放在本机，运行 Agent 时由所选宿主及模型处理相关上下文。
